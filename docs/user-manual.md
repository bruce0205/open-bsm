# OpenBSM 使用手冊

OpenBSM 是適用於 macOS Apple Silicon 的 Boshiamy 相容繁體中文輸入法。
本手冊依據目前已實作的功能編寫，適用於 OpenBSM `0.1.0`。

## 系統需求

- Apple Silicon Mac。
- macOS `13` 或更新版本。

## 安裝與啟用

### 使用目前使用者安裝

如果是從原始碼取得 OpenBSM，可在專案目錄執行：

```bash
make install
```

安裝完成後，請登出 macOS，再重新登入。

### 在系統設定中加入輸入法

1. 開啟「系統設定」。
2. 進入「鍵盤」→「文字輸入」→「編輯」。
3. 按一下「＋」。
4. 在「繁體中文」分類中加入「OpenBSM」。

完成後，從 macOS 的輸入法選單選取 OpenBSM，即可開始使用。

OpenBSM 預設使用中文模式。若已啟用中英文模式記憶，啟動時會依記憶設定還原模式。

### 使用 DMG 或 PKG

開發版 DMG 中的 `OpenBSM.app` 可複製到目前使用者的輸入法目錄：

```text
~/Library/Input Methods/
```

若使用 PKG 安裝程式，OpenBSM 會安裝至：

```text
/Library/Input Methods/
```

PKG 安裝需要管理者授權。開發版使用 ad-hoc 簽署，第一次開啟時 macOS 可能需要在「隱私權與安全性」中允許執行。

## 基本輸入

1. 確認目前輸入法為 OpenBSM，且處於中文模式。
2. 輸入 Boshiamy 字根序列。
3. 從候選列選取候選字。
4. 按下 `Space` 或 `Enter` 輸入目前反白的候選字。

每頁最多顯示 `9` 個候選字。若字根沒有完全相符的候選字，按下 `Space` 或 `Enter` 會直接輸入目前的字根文字。

### 編輯組字中的字根

- `Backspace`：刪除最後一個字根。
- `Escape`：取消目前組字。
- 字根最多可輸入 `5` 個字元。
- 英文字母可先輸入，即使目前尚未形成完整候選字。
- 符號只有在仍是碼表中某個字根的前綴時才會被接受。

### 選取候選字

- `1` ～ `9`：直接選取目前頁面對應編號的候選字。
- `←`、`↑`：選取上一個候選字。
- `→`、`↓`：選取下一個候選字。
- `Page Up`：切換到上一頁候選字。
- `Page Down`：切換到下一頁候選字。
- 使用滑鼠點選候選字或候選列的翻頁按鈕，也可以完成選取。

## 中英文模式

### 快捷鍵切換

按下 `Shift + Space`，可在中文模式與直接英文輸入模式之間切換。

此快捷鍵只在 OpenBSM 啟用時註冊，不需要「輸入監控」或「輔助使用」權限。切換模式時，若仍有未完成的中文組字，OpenBSM 會先提交目前組字。

### 從輸入法選單切換

在 macOS 輸入法選單中選擇：

- 「切換至中文模式」
- 「切換至英文模式」

### 中英文模式記憶

在 OpenBSM 輸入法選單中，可切換：

- 「中英文模式記憶：依 App」：不同 App 分別記住中文或英文模式。這是預設設定。
- 「中英文模式記憶：所有 App 共用」：所有 App 共用同一個中文或英文模式。

設定會保存於輸入法重新啟動及 App 重開之後。切換記憶範圍時，會保留目前 App 的模式。

## 半型與全型

按下 `Control + Shift + Space`，可在半型與全型之間切換。

也可以從 OpenBSM 輸入法選單選擇：

- 「字元寬度：半型」
- 「字元寬度：全型」

全型模式的行為如下：

- 直接輸入的可列印 ASCII 字元會轉換為 Unicode 全型字元。
- ASCII 空白也會轉換為全型空白。
- Boshiamy 字根、候選字選取數字、方向鍵、翻頁鍵與快捷鍵不會被轉換。
- 候選列會顯示「全」，提示目前正在使用全型模式。

字元寬度設定對所有 App 共用，會在輸入法重新啟動後保留，預設為半型。

## 標點符號與特殊符號

標點符號與特殊符號依照碼表字根查詢，不使用固定寫死的轉換規則。例如：

```text
.s + Space → ♠
```

實際可用的字根取決於目前載入的碼表。全型模式下，未被碼表字根處理的直接輸入 ASCII 標點符號，會轉換為對應的全型字元。

## 候選列主題

從 OpenBSM 輸入法選單選擇下列項目，可以切換候選列主題：

- 「切換為淺色候選列」
- 「切換為深色候選列」

OpenBSM 預設使用深色候選列。主題設定會同時套用到候選列與反查碼列，並會保存下來。

## 候選字學習

使用 `Space`、`Enter`、數字鍵或滑鼠提交候選字時，OpenBSM 會記錄該字根的使用情況。

之後相同字根的候選字會依下列順序排列：

1. 使用次數較多者優先。
2. 使用次數相同時，最近使用者優先。
3. 尚未學習的候選字維持原始碼表順序。

學習資料儲存在本機：

```text
~/Library/Application Support/OpenBSM/frequency.json
```

選擇「重置候選字學習…」並確認後，會刪除所有候選字使用次數與最近使用紀錄。重新載入個人碼表時，已不存在於合併碼表的學習紀錄會自動移除。

## 個人碼表

### 開啟個人碼表

從 OpenBSM 輸入法選單選擇「編輯個人碼表…」。OpenBSM 會建立並開啟以下檔案：

```text
~/Library/Application Support/OpenBSM/user.txt
```

編輯並儲存後，選擇「重新載入個人碼表」，新的設定會立即套用。重新載入時，若有尚未完成的組字，OpenBSM 會先提交該組字；目前的中文或英文模式會保留。

### 檔案格式

一般候選字可使用空白分隔：

```text
addr bruce@example.com
```

候選字包含空白時，請使用 Tab 分隔欄位：

```text
sig<TAB>Bruce Hsu
cmd<TAB>git push origin main<TAB>git status
```

其中 `<TAB>` 代表實際的 Tab 字元，不是要輸入的文字 `<TAB>`。每行第一個欄位是字根，後續欄位都是候選字。

其他規則：

- 空白行與 `#` 開頭的註解行會被忽略。
- 字根會自動轉為小寫。
- 相同字根的候選字會合併，重複候選字只保留一份。
- 個人碼表中的候選字會排在內建碼表候選字之前。
- 個人碼表不會寫入 App，因此重新建置或重新安裝 OpenBSM 後仍會保留。

## 反查碼

反查碼可查詢目前選取文字的字根。

1. 在目前 App 中選取一個字元。
2. 按下 `Option + Shift + R`。
3. 反查碼列會顯示該字元的一組字根。
4. 再按一次 `Option + Shift + R`，可切換到下一組字根。
5. 也可以使用反查碼列的上一組／下一組按鈕。
6. 按下 `Escape` 關閉反查碼列。

反查碼一次只接受一個非空白字元。若沒有選取文字，或同時選取多個字元，反查碼列不會開啟。

反查碼需要目前 App 支援透過 InputMethodKit 提供選取文字。如果 App 不支援文件存取，OpenBSM 會維持原本選取內容，且不顯示反查碼列。

## 輸入法選單功能

OpenBSM 輸入法選單提供以下功能：

- 切換中文／英文模式。
- 切換半型／全型字元寬度。
- 切換深色／淺色候選列。
- 設定中英文模式記憶範圍。
- 編輯個人碼表。
- 重新載入個人碼表。
- 重置候選字學習紀錄。

## 常見操作問題

### 安裝後找不到 OpenBSM

請先確認已將 OpenBSM 加入「系統設定」→「鍵盤」→「文字輸入」→「編輯」中的輸入法清單，然後登出並重新登入 macOS。

### 按下字根沒有候選字

請確認目前是中文模式，並檢查字根是否存在於內建或個人碼表。若字根沒有完全相符的候選字，按下 `Space` 或 `Enter` 仍會提交目前字根文字。

### 個人碼表修改後沒有生效

儲存 `user.txt` 後，請從 OpenBSM 輸入法選單選擇「重新載入個人碼表」。

### 候選字順序改變

這是候選字學習功能的預期行為。若要恢復原始順序，請選擇「重置候選字學習…」。
